01 · Hva du skal gjøre

Oppgaven og formuleringen

Assignment-forelesning 2 · slides 2–13, 16–22 · bygger på forelesning 4 og boka kap. 5 · pseudokode: Boka s. 171 og 176

Du får csp.py (CSP-klassen), map_coloring.py (Australia-kartet, til testing) og sudoku.py. To metoder mangler: ac_3() og backtracking_search(), begge etter standard-pseudokoden. Kjør først AC-3 på hvert brett, så backtracking. At AC-3 løser de enkle brettene alene er helt greit.

Leveransen: kode, og én PDF med løsningen for hvert av de fire brettene, domenene etter AC-3, hvor mange ganger backtrack() ble kalt og returnerte failure, kjøretider, og en kort diskusjon, f.eks. hvorfor AC-3 kutter kjøretiden kraftig på noen brett.

Sudoku som CSP
81 variabler, domener 1–9, ≠ mellom naboer

Variabler: én per celle, \(X_{11}, \dots, X_{99}\) (rad, kolonne). Domener: \(\{1, \dots, 9\}\) for tomme celler, \(\{v\}\) for celler med gitt tall \(v\). Constraints: Alldiff for hver rad, kolonne og 3×3-boks. Koden gjør hver Alldiff over 9 celler om til alle \(\binom{9}{2} = 36\) binære kanter \(X_i \ne X_j\). Hver celle får da 20 naboer (8 i raden, 8 i kolonnen, 4 til i boksen), altså \(81 \cdot 20 / 2 = 810\) ulike kanter (egen regning).

Valgene i backtracking er fri: SELECT-UNASSIGNED-VARIABLE kan være hva som helst, men MRV er et godt valg. ORDER-DOMAIN-VALUES kan være hva som helst, gjerne LCV. INFERENCE er der forward checking ville vært; den kan hoppes over.

function AC-3(csp) returns false if an inconsistency is found and true otherwise
  queue ← a queue of arcs, initially all the arcs in csp
  while queue is not empty do
    (Xi, Xj) ← POP(queue)
    if REVISE(csp, Xi, Xj) then
      if size of Di = 0 then return false
      for each Xk in Xi.NEIGHBORS - {Xj} do
        add (Xk, Xi) to queue
  return true

function REVISE(csp, Xi, Xj) returns true iff we revise the domain of Xi
  revised ← false
  for each x in Di do
    if no value y in Dj allows (x,y) to satisfy the constraint between Xi and Xj then
      delete x from Di
      revised ← true
  return revised

function BACKTRACKING-SEARCH(csp) returns a solution or failure
  return BACKTRACK(csp, { })

function BACKTRACK(csp, assignment) returns a solution or failure
  if assignment is complete then return assignment
  var ← SELECT-UNASSIGNED-VARIABLE(csp, assignment)
  for each value in ORDER-DOMAIN-VALUES(csp, var, assignment) do
    if value is consistent with assignment then
      add {var = value} to assignment
      inferences ← INFERENCE(csp, var, assignment)
      if inferences ≠ failure then
        add inferences to csp
        result ← BACKTRACK(csp, assignment)
        if result ≠ failure then return result
        remove inferences from csp
      remove {var = value} from assignment
  return failure
02 · Gjennomgåtte eksempler

Små regneeksempler

Assignment-forelesning 2 · slides 5–6, 9–12, 14–15, 23 · min-conflicts: Boka kap. 5.4
Oppgave fra assignment-forelesningenslides 9–12

Formuler Australia-kartfargingen som CSP (variabler, domener, constraints). Hva er én løsning backtracking kan returnere?

Svar fra assignment-forelesningen

\(X\) = {WA, NT, Q, NSW, V, SA, T}. Domene {red, green, blue} for alle. Kanter (naboer må ha ulik farge): SA–WA, SA–NT, SA–Q, SA–NSW, SA–V, WA–NT, NT–Q, Q–NSW, NSW–V. T har ingen naboer.

Eksempelutskrift: {'WA': 'red', 'NT': 'green', 'Q': 'red', 'NSW': 'green', 'V': 'red', 'SA': 'blue', 'T': 'red'}. Bruk dette til å teste koden før Sudoku.

De tre neste oppgavene bruker samme lille graf: tre variabler i en kjede, alle med domene {B, G, R} (blå, grønn, rød), og ≠ langs kantene. «Feil» betyr her at backtracking prøver en verdi som bryter med en variabel som allerede har verdi (egen tolkning, uten forward checking).

Oppgave fra assignment-forelesningenslides 14–15

Bruk MRV for variabler og LCV for verdier, alfabetisk tie-break. Er MRV + LCV bedre enn tilfeldige valg i snitt for grafen over?

Svar fra assignment-forelesningen

Nei. Med heuristikkene får du garantert 1 feil; tilfeldig gir ca. 0,704 i snitt.

Med heuristikkene (mellomregning): alle har 3 verdier, så MRV velger alfabetisk A. For A utelukker hver farge én verdi hos B, så LCV velger alfabetisk B (blå). Nå har B 2 lovlige verdier og C 3, så MRV velger B. LCV: hver farge utelukker én verdi hos C, alfabetisk B (blå) først. Den bryter A ≠ B: 1 feil. Så G, deretter C = B. Ferdig.

Tilfeldig: i 4 av 6 variabelrekkefølger kommer B først eller nest først. Da har B og den siste variabelen hver én forbudt farge, og sjansen for å prøve den først er 1/3: \(1/3 + 1/3 = 2/3\) forventede feil. I de 2 rekkefølgene der B er sist (A, C, B eller C, A, B): med sannsynlighet 1/3 har A og C samme farge, og B har én forbudt verdi (1/3 feil). Med sannsynlighet 2/3 har de ulik farge, og B har to forbudte verdier (i snitt 1 feil). Det gir \(1/9 + 2/3 = 7/9\).

\[ \frac{4 \cdot \frac{2}{3} + 2 \cdot \frac{7}{9}}{6} \approx 0{,}704 \lt 1 \]
Oppgave fra assignment-forelesningenslide 23

Anta at A settes til blå. Hvordan ser domenene ut etter AC-3?

Svar fra assignment-forelesningen

B sitt domene blir {G, R}.

Mellomregning: køen starter med alle buer i begge retninger: (A,B), (B,A), (B,C), (C,B). REVISE(B, A): verdien B hos B har ingen støtte i \(D_A = \{B\}\), slettes, og (C, B) legges i køen igjen. REVISE(C, B): hver farge hos C har en ulik farge i {G, R}, ingenting slettes. Resultat: A = {B}, B = {G, R}, C = {B, G, R}.

Oppgave fra assignment-forelesningenslide 23

Etter AC-3 med A = blå: er MRV + LCV bedre enn tilfeldige valg nå? Alfabetisk tie-break.

Forslag til svar · ikke fasit fra assignment-forelesningen

Ja. MRV velger B (2 verdier mot 3 hos C). LCV: G og R utelukker hver én verdi hos C, alfabetisk G. G er lovlig siden AC-3 har fjernet blå. Så C: B (blå) er lovlig ved siden av G. 0 feil.

Tilfeldig: tar du B først, er begge verdiene lovlige, og C har én forbudt farge: 1/3 feil. Tar du C først, er alt lovlig for C; med sannsynlighet 2/3 får C grønn eller rød, og da har B én av to verdier forbudt: \(2/3 \cdot 1/2 = 1/3\). Snitt 1/3 feil mot 0. Poenget: AC-3 fjerner nettopp de verdiene heuristikkene ellers snublet i.

Tenk over · fra assignment-forelesningenslide 22 (f)

Hvorfor kan AC-3 kutte kjøretiden drastisk på noen Sudoku-brett?

Forslag til svar · ikke fasit fra assignment-forelesningen

Hvert gitt tall fjernes fra domenet til sine 20 naboer. Når et domene krymper til én verdi, fjernes den verdien fra dens naboer, og slik forplanter det seg. På enkle brett ender alle domener med én verdi, så backtracking bare leser av løsningen uten å gå tilbake. På vanskelige brett står noen domener igjen med flere verdier, men søketreet er likevel mye mindre enn med domener på 9.

Tenk over · fra assignment-forelesningenslide 6

8-dronningproblemet ble brukt som eksempel for genetiske algoritmer. Er en genetisk algoritme eller en CSP-løser mest effektiv? Hvorfor?

Forslag til svar · ikke fasit fra assignment-forelesningen

CSP-løseren. Problemet har en ren constraint-struktur: én variabel per kolonne (raden til dronningen), domene 1–8, og binære constraints «ikke samme rad, ikke samme diagonal». Backtracking med propagering (forward checking/AC-3) og MRV kutter bort ulovlige delløsninger tidlig, finner en løsning som garantert er gyldig, og kan bevise at ingen finnes. Lokalt søk med min-conflicts løser n-dronninger svært raskt selv for stor n.

GA er stokastisk og bruker constraints bare indirekte via fitness (antall angrepspar). Crossover kan bryte gode delløsninger, den trenger mange evalueringer, og gir ingen garanti for å finne en løsning eller vite at den er optimal.

03 · Vanlige feil

Hvor poengene forsvinner

Assignment-forelesning 2 · slides 3, 13–15, 21, 23 · pluss egne erfaringspunkter
Vanlige feil
  • Buer bare én vei. Hver kant gir to buer, \((X_i, X_j)\) og \((X_j, X_i)\). Arc-consistent betyr at alle buer er konsistente.
  • REVISE endrer feil domene. REVISE\((X_i, X_j)\) sletter bare fra \(D_i\). Etter en endring legges \((X_k, X_i)\) inn for alle andre naboer \(X_k\), ikke \((X_i, X_k)\).
  • Glemmer tom-domene-sjekken. Blir et domene tomt, returnerer AC-3 false: ingen løsning.
  • MRV og LCV byttet om. MRV velger variabel (færrest lovlige verdier igjen), LCV ordner verdier (den som utelukker færrest verdier hos naboene først).
  • MRV teller opprinnelig domene. Det er antall lovlige verdier gitt nåværende tilordning som teller.
  • Glemmer tie-break. Eksamen gir en regel (alfabetisk e.l.); vis den i hvert steg.
  • Angrer ikke ved backtracking. Fjern både {var = value} og inferensene før neste verdi prøves.
  • Leser ikke læreboka. Assistenten advarer: i 2025 kom et tema som bare sto i læreboka (topologisk sortering, nå ute av pensum).
