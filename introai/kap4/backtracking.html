Backtracking med MRV og LCV

Backtracking search tildeler én variabel om gangen og går tilbake ved blindvei. Rekkefølgen styres av MRV (variabel) og LCV (verdi), og inferens som forward checking oppdager blindveier tidlig. Eksamen ber deg vise hvert steg med domener.

01 · Algoritmen

Backtracking search

Slides forelesning 4 · 12, 33 · Boka kap. 5.3
Deltema 4.3 · prio 1

Backtracking search er dybde-først-søk der hvert nivå tildeler én variabel. Fordi CSP er kommutative (rekkefølgen tildelingene gjøres i, påvirker ikke resultatet), holder det å se på én variabel per nivå. Hvis ingen verdi er konsistent, returneres failure og forrige variabel prøver neste verdi.

function BACKTRACKING-SEARCH(csp) returns a solution or failure
  return BACKTRACK(csp, { })

function BACKTRACK(csp, assignment) returns a solution or failure
  if assignment is complete then return assignment
  var ← SELECT-UNASSIGNED-VARIABLE(csp, assignment)
  for each value in ORDER-DOMAIN-VALUES(csp, var, assignment) do
    if value is consistent with assignment then
      add {var = value} to assignment
      inferences ← INFERENCE(csp, var, assignment)
      if inferences ≠ failure then
        add inferences to csp
        result ← BACKTRACK(csp, assignment)
        if result ≠ failure then return result
        remove inferences from csp
      remove {var = value} from assignment
  return failure

Tre steder å gjøre søket smartere: SELECT-UNASSIGNED-VARIABLE (MRV, degree), ORDER-DOMAIN-VALUES (LCV) og INFERENCE (forward checking eller AC-3/MAC). Uten dem velges variabler og verdier i fast rekkefølge.

02 · Variabelvalg

MRV og degree

Slides forelesning 4 · 34–35 · Degree: Boka kap. 5.3.1 (ikke i slidene)
Definisjon
Minimum remaining values (MRV)

Velg den utildelte variabelen med færrest gjenværende lovlige verdier (minste gjenværende domene). Kalles også «most constrained variable» eller «fail-first»: variabelen som mest sannsynlig feiler, tas først, så blindveier oppdages høyt i treet.

MRV hjelper ikke i starten når alle domener er like store. Da brukes degree-heuristikken som tie-breaker: velg variabelen som inngår i flest constraints med andre utildelte variabler. I Australia har SA grad 5 og velges først. Står det fortsatt likt, brukes tie-break-regelen i oppgaven (alfabetisk/numerisk).

Oppgave fra slideneSlide 34–35

Kartfarging med \(X_1 = \text{red}\), \(X_2 = \text{green}\), \(D_3 = \{\text{blue}\}\), \(D_4 = \{\text{red}, \text{blue}\}\). Velger MRV \(X_3\) eller \(X_4\)?

Svar fra slidene

\(X_3\): én gjenværende verdi mot to for \(X_4\).

03 · Verdivalg

Least constraining value

Slides forelesning 4 · 36–37 · Boka kap. 5.3.1
Definisjon
Least constraining value (LCV)

Når variabelen er valgt: prøv først verdien som utelukker færrest verdier hos naboene i constraint graph, altså minst reduksjon i de utildelte domenene ved forward checking. «Fail-last»: vi trenger bare én løsning, så vi prøver den verdien som lar flest muligheter stå åpne.

Regn LCV slik: for hver verdi \(x\), tell hvor mange verdier som forsvinner fra domenene til utildelte naboer om \(X = x\). Minst tall først. Har variabelen ingen utildelte naboer, blir det uavgjort, og tie-break-regelen avgjør.

Ikke bland

MRV velger den mest begrensede variabelen, LCV den minst begrensende verdien. Løsningsforslaget for 2022 kaller dem «Max-conflicts» og «Min-conflicts». Det er ikke det samme som den lokale søkealgoritmen MIN-CONFLICTS.

Oppgave fra slideneSlide 36–37

Samme tilstand som over, men \(X_4\) er valgt. Velger LCV red eller blue?

Svar fra slidene · begrunnelse lagt til

Red. Eneste utildelte nabo er \(X_3\) med \(D_3 = \{\text{blue}\}\). \(X_4 = \text{blue}\) fjerner blue og tømmer \(D_3\) (1 verdi utelukket); \(X_4 = \text{red}\) fjerner ingenting (0).

04 · Søk og inferens

Forward checking i søket

Slides forelesning 4 · 16, 25–28, 40 (boka fig. 5.6) · Boka kap. 5.3.2

INFERENCE kjøres etter hver tildeling. Med forward checking fjernes verdier fra de utildelte naboene; blir et domene tomt, er tildelingen en blindvei, og vi prøver neste verdi uten å gå dypere. MAC (maintaining arc consistency) kjører i stedet AC-3 med buene \((X_j, X_i)\) inn mot den tildelte variabelen og fanger mer (se 4A). MRV og forward checking passer godt sammen: forward checking holder domenene oppdatert, og MRV leser dem.

Prøv selv · Backtracking stegvis

Uten heuristikk velges variabler alfabetisk og verdier i rekkefølgen rød, grønn, blå. MRV velger færrest lovlige verdier (likt ⇒ alfabetisk). MRV + LCV sorterer i tillegg verdiene etter hvor mange verdier de utelukker hos naboene. Prikkene er domenene: med forward checking av krymper de ikke, og en blindvei oppdages først når variabelen selv er tom. Graf G er laget for å vise forskjellen; Australia går uten backtracking uansett innstilling, men se hvordan forward checking krymper domenene.

05 · Eksamen

Firesifret tall med MRV og LCV

Eksamen Ord. 2022 oppg. 4.2
Eksamen Ord. 2022 · oppg. 4.2Firesifret tall

Løs CSP-en fra 4.1 (\(x_1 \lt x_2 \lt x_3 \lt x_4\), sifre 1–5, tallet odde) med backtracking. Bruk minimum remaining values for variabelvalg og least constraining value for verdivalg. Vis hvert steg med oppdaterte domener.

Svar fra løsningsforslaget · steg skrevet ut, med én rettelse

Start etter unær constraint: \(D_1 = D_2 = D_3 = \{1,\dots,5\}\), \(D_4 = \{1, 3, 5\}\). Domenene oppdateres med forward checking (sensor godtok AC-3 eller forward checking). Tie-break numerisk.

  1. MRV: \(x_4\) (3 verdier mot 5). LCV på eneste nabo \(x_3\) (\(x_3 \lt x_4\)): \(x_4 = 1\) fjerner 5 verdier, \(x_4 = 3\) fjerner 3, \(x_4 = 5\) fjerner 1 ⇒ \(x_4 = 5\). FC: \(D_3 = \{1,2,3,4\}\).
  2. MRV: \(x_3\) (4 mot 5 og 5). LCV på nabo \(x_2\): \(x_3 = 4\) fjerner {4, 5} (2), 3 fjerner 3, 2 fjerner 4, 1 fjerner 5 ⇒ \(x_3 = 4\). FC: \(D_2 = \{1,2,3\}\). Sjekk: \(5 \gt 4\).
  3. MRV: \(x_2\) (3 mot 5). LCV på nabo \(x_1\): \(x_2 = 3\) fjerner {3, 4, 5} (3), 2 fjerner 4, 1 fjerner 5 ⇒ \(x_2 = 3\). FC: \(D_1 = \{1, 2\}\).
  4. MRV: \(x_1\), eneste igjen. Ingen utildelte naboer ⇒ uavgjort ⇒ numerisk: \(x_1 = 1\).
  5. Odde-sjekk: \(1345 \bmod 2 = 1\). Ingen backtracking.

Løsning: \(x_1 = 1, x_2 = 3, x_3 = 4, x_4 = 5\), tallet 1345.

Om løsningsforslaget: det legger først til de implisitte constraintene \(x_4 \gt x_1, x_4 \gt x_2, \dots\) (strengt ordnet), så alle domener krymper etter \(x_4 = 5\), og ender på 1245. I steg 3 sier det at \(x_2 = 2\) og \(x_2 = 3\) utelukker like mange verdier og velger 2 numerisk. Etter LCV-definisjonen fjerner \(x_2 = 3\) færre verdier fra \(D_1\) (\(\{1, 2\}\) blir igjen, mot \(\{1\}\)), så 3 er riktig LCV-valg. Begge tallene oppfyller alle constraints; på eksamen er det stegene med domener som gir poeng.

07 · Assignment-forelesningen

MRV + LCV mot tilfeldige valg

Assignment-forelesning 2 · slides 14–15 og 23

Kjeden A – B – C med domene {B, G, R} for alle og ulik farge på naboer. «Feil» betyr å prøve en verdi som bryter en constraint med det som alt er tildelt. Slidene regner uten inferens, så domenene krymper ikke.

Oppgave fra slideneAssignment-forelesning 2 · slide 14–15

Anta MRV for variabler og LCV for verdier, med alfabetisk tie-break. Er MRV + LCV bedre enn tilfeldige valg i snitt for grafen A – B – C?

Svar fra slidene · MRV+LCV-stegene er vår rekonstruksjon

MRV + LCV: nøyaktig 1 feil. Alle domener har 3 verdier ⇒ alfabetisk A. LCV: hver farge fjerner én verdi fra B ⇒ likt ⇒ A = B(lå). Så B (alfabetisk), LCV likt igjen ⇒ B(lå) først: bryter med A, 1 feil; deretter G. C: B(lå) er lov.

Tilfeldig: ≈ 0,704 feil i snitt. 6 like sannsynlige variabelrekkefølger.

  • B først eller i midten (4 av 6): hver av de to variablene etter den første nabotildelingen treffer den forbudte fargen med sannsynlighet 1/3 ⇒ \(1/3 + 1/3 = 2/3\).
  • B sist (2 av 6): A og C har samme farge med sannsynlighet 1/3, og da er én farge forbudt for B ⇒ 1/3 forventet feil. Ulik farge (2/3): to forbudte, forventet \(2/3 + 2/3 \cdot 1/2 = 1\) feil. Til sammen \(1/3 \cdot 1/3 + 2/3 \cdot 1 = 7/9\).
\[ E[\text{feil}] = \frac{4 \cdot \tfrac{2}{3} + 2 \cdot \tfrac{7}{9}}{6} = \frac{38/9}{6} \approx 0{,}704 \]

Så nei: MRV + LCV (1 feil) er her dårligere enn tilfeldig (0,704). Uten inferens har heuristikkene bare uavgjorte valg, og den alfabetiske tie-breaken er uheldig.

Oppgave fra slideneAssignment-forelesning 2 · slide 23

Nå gjør vi A blå og kjører AC-3, som gir \(D_B = \{G, R\}\) (se 4A). Er MRV + LCV bedre enn tilfeldige valg nå? Alfabetisk tie-break.

Forslag til svar · ikke fasit fra slidene

MRV + LCV: 0 feil. MRV: B (2 verdier) før C (3). LCV for B: G fjerner G fra C, R fjerner R ⇒ likt ⇒ G. C: ingen utildelte naboer ⇒ alfabetisk B(lå), som er lov fordi B = G.

Tilfeldig: 1/3 feil i snitt. B trekker fra {G, R} og kan ikke feile mot A. Tildeles B først, treffer C Bs farge med sannsynlighet 1/3. Tildeles C først, har C ingen tildelte naboer; deretter feiler B bare om C fikk G eller R (2/3) og B trekker den (1/2): \(2/3 \cdot 1/2 = 1/3\).

Ja, nå er MRV + LCV bedre (0 mot 1/3): inferensen gjorde domenene ulike, og da har heuristikkene noe å gå etter.

08 · Øv selv

Kartfarging med alle heuristikkene

Egen oppgave av eksamenstypen · kart fra slides forelesning 4 · 6
Egen oppgave · eksamenstypeAustralia, 7 regioner

Farg Australia (WA, NT, SA, Q, NSW, V, T; domene {R, G, B}) med backtracking og forward checking. Variabelvalg: MRV, degree som første tie-break, deretter alfabetisk. Verdivalg: LCV, tie-break i rekkefølgen R, G, B. Vis hvert steg med domenene.

Forslag til svar · ikke fasit fra slidene
  1. Alle har 3 verdier. Degree: SA 5, NT/Q/NSW 3, WA/V 2, T 0 ⇒ SA. LCV: hver farge fjerner 1 verdi hos 5 naboer (5) ⇒ likt ⇒ SA = R. FC: WA, NT, Q, NSW, V = {G, B}; T = {R, G, B}.
  2. MRV: WA, NT, Q, NSW, V har 2. Degree mot utildelte: WA 1 (NT), NT 2, Q 2, NSW 2, V 1 (NSW) ⇒ NT, NSW, Q likt ⇒ alfabetisk NSW. LCV: G fjerner G fra Q og V (2), B fjerner B fra Q og V (2) ⇒ NSW = G. FC: Q = {B}, V = {B}.
  3. MRV: Q og V har 1. Degree: Q 1 (NT), V 0 ⇒ Q = B. FC: NT = {G}.
  4. MRV: NT og V har 1. Degree: NT 1 (WA), V 0 ⇒ NT = G. FC: WA = {B}.
  5. MRV: V og WA har 1, degree 0 begge ⇒ alfabetisk V = B.
  6. WA = B. 7. T: {R, G, B}, ingen naboer ⇒ T = R.

Løsning: SA = R, NSW = G, Q = B, NT = G, V = B, WA = B, T = R. Ingen backtracking: MRV + degree fant de «vanskelige» regionene først.

Sjekk forståelsen · Middels
Hvorfor brukes degree-heuristikken bare som tie-breaker, ikke alene?
Degree ser bare på grafstrukturen, ikke på hvor mange verdier som er igjen. MRV fanger direkte hvem som er nærmest å feile (en variabel med 0 verdier velges straks). Degree er nyttig når MRV er uavgjort, typisk i starten når alle domener er like.

Test deg selv

Spørsmål 1 · Lett
Hvorfor velger MRV den mest begrensede variabelen, mens LCV velger den minst begrensende verdien?
Alle variabler må tildeles uansett, så det lønner seg å feile tidlig (mindre tre under blindveien). Men vi trenger bare én verdi som fungerer, så vi prøver den som mest sannsynlig lar resten gå opp.
Spørsmål 2 · Middels
Backtracking uten forward checking: \(D_A = \{1,2\}\), \(D_B = \{1,2,3\}\), \(D_C = \{1\}\), constraints \(A \ne B\), \(B \ne C\), \(A \lt B\). Hvilken variabel og verdi velger MRV + LCV først (numerisk tie-break)?
MRV: C (1 verdi) ⇒ C = 1. Lovlige nå: A {1, 2}, B {2, 3} ⇒ likt ⇒ numerisk/alfabetisk A. LCV for A mot B: A = 1 utelukker ingen av Bs lovlige verdier, A = 2 utelukker 2 ⇒ A = 1. Til slutt B: {2, 3}, ingen utildelte naboer ⇒ B = 2.
Spørsmål 3 · Vanskelig
I widgeten gir Graf G mange backtracks uten heuristikk og uten forward checking, færre med forward checking, og ingen med MRV + LCV. Forklar hvorfor forward checking alene hjelper.
Uten forward checking oppdages en blindvei først når søket kommer til variabelen som ikke har lovlige verdier, kanskje flere nivåer lenger ned. Forward checking tømmer domenet med en gang den tildelingen som ødela det gjøres, så søket prøver neste verdi høyere opp og slipper å utforske hele undertreet.
