02 · k-means

Fra bunnen og med sklearn

Notatene · avsnitt 3.1.1 · s. 43–44 (stegene); koden er forslag

De sju stegene fra 3A oversatt til kode. Det eneste som trengs er avstander, argmin og mean; løkka stopper når ingen punkter bytter klynge.

def kmeans(X, k, init="pp", max_iter=100, rng=np.random.default_rng(0)):
    C = init_centroids(X, k, init, rng)                      # steg 1–2: k sentroider, shape (k, d)
    labels = rng.integers(0, k, size=len(X))                 # steg 3: tilfeldig klynge til hvert punkt
    for _ in range(max_iter):
        dist = ((X[:, None, :] - C[None, :, :]) ** 2).sum(axis=2)   # steg 4: (n, k) kvadrerte avstander
        new_labels = dist.argmin(axis=1)                     # steg 5: nærmeste sentroide
        if np.all(new_labels == labels):                     # steg 7: ingen endring → ferdig
            break
        labels = new_labels
        C = np.array([X[labels == j].mean(axis=0) if np.any(labels == j) else C[j]
                      for j in range(k)])                    # steg 6: middelverdi per klynge
    inertia = dist[np.arange(len(X)), labels].sum()          # det k-means minimerer
    return C, labels, inertia


def init_centroids(X, k, init, rng):
    if init == "random":                                     # k tilfeldige datapunkter
        return X[rng.choice(len(X), k, replace=False)].copy()
    C = [X[rng.integers(len(X))]]                            # første alltid tilfeldig
    while len(C) < k:
        d2 = np.min(((X[:, None, :] - np.array(C)[None, :, :]) ** 2).sum(axis=2), axis=1)  # avstand² til nærmeste sentroide
        if init == "far":                                    # lengst unna: deterministisk, havner i utkanten
            C.append(X[d2.argmax()])
        else:                                                # k-means++: sannsynlighet ∝ d²
            C.append(X[rng.choice(len(X), p=d2 / d2.sum())])
    return np.array(C)

Sannsynligheten for at tilfeldig start setter én sentroide i hver sanne klynge er \(k!/k^k\); det er grunnen til at init="pp" er standard.

Det samme med scikit-learn

from sklearn.cluster import MiniBatchKMeans                   # klassen ligger i sklearn.cluster

km = MiniBatchKMeans(n_clusters=3, init="k-means++", batch_size=256, random_state=0).fit(X)
km.labels_            # klynge per punkt
km.cluster_centers_   # sentroidene, shape (k, d)
km.inertia_           # sum av kvadrerte avstander punkt–sentroide

Særlig for store datasett: i stedet for hele datasettet brukes en liten tilfeldig trekning (en mini batch) hver iterasjon. \(k\) angis med n_clusters, initialiseringsmetoden med init. Oppgir vi ikke \(k\), prøver algoritmen å velge en optimal verdi selv; det fungerer vel så ofte mindre godt.

03 · Velge k

Tre metrikker, én løkke

Notatene · avsnitt 3.1.1 · s. 45 (metrikkene); koden er forslag

Uten labels må \(k\) velges ved å tilpasse flere modeller og sammenlikne metrikker. Inertia synker alltid med \(k\), så den brukes bare til å se etter en «albue». Silhouette og Calinski–Harabasz har et maksimum, men ikke nødvendigvis ved samme \(k\).

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, calinski_harabasz_score

for k in range(2, 11):
    km = KMeans(n_clusters=k, init="k-means++", n_init=10, random_state=0).fit(X)
    print(k,
          round(km.inertia_, 1),                                # lav er bra, men synker alltid med k
          round(silhouette_score(X, km.labels_), 3),            # (b − a) / max(a, b), 1 er best
          round(calinski_harabasz_score(X, km.labels_), 1))     # mellom / innad, høy er bra
def silhouette_one(i, X, labels):                             # for ett punkt, for å se formelen
    same = X[(labels == labels[i])]
    a = np.linalg.norm(same - X[i], axis=1).sum() / max(len(same) - 1, 1)   # midlere avstand innad
    b = min(np.linalg.norm(X[labels == j] - X[i], axis=1).mean()
            for j in set(labels) if j != labels[i])                         # midlere avstand til nærmeste andre klynge
    return (b - a) / max(a, b)

Skaler features før alt dette: euklidsk avstand domineres ellers av featuren med størst tallverdi, og det gjelder både k-means og metrikkene.

04 · DBSCAN

Kjernepunkter som sprer klyngen

Notatene · avsnitt 3.1.2 · s. 45 (prosedyren); koden er forslag

De tre stegene fra 3A: finn kjernepunkter (nok naboer innenfor \(\epsilon\)), spre klyngen fra kjernepunkt til kjernepunkt, og la alt som ikke ble nådd være outliers (label \(-1\)).

def dbscan(X, eps, min_samples):
    n = len(X)
    dist = np.linalg.norm(X[:, None, :] - X[None, :, :], axis=2)    # (n, n): alle avstander, derfor treg for stor n
    neighbors = [np.where((dist[i] <= eps) & (np.arange(n) != i))[0] for i in range(n)]
    core = np.array([len(nb) >= min_samples for nb in neighbors])  # steg 1: kjernepunkter
    labels = np.full(n, -1)                                         # -1 = ikke tilordnet (outlier)
    cluster = 0
    for i in range(n):
        if not core[i] or labels[i] != -1:
            continue
        labels[i] = cluster                                         # start ny klynge i et kjernepunkt
        stack = [i]
        while stack:                                                # steg 2: spre klyngen
            p = stack.pop()
            for q in neighbors[p]:
                if labels[q] == -1:
                    labels[q] = cluster                             # nås fra p: samme klynge
                    if core[q]:
                        stack.append(q)                             # bare kjernepunkter sprer videre
        cluster += 1
    return labels, core                                             # steg 3: labels == -1 er outliers

Ikke-kjernepunktene er de med labels != -1 og core == False: de ble nådd fra et kjernepunkt, men sprer ikke selv. Kjeden i løkka er nøyaktig definisjonen «to punkter er i samme klynge når det ene kan nås fra det andre med steg \(\le \epsilon\)».

Det samme med scikit-learn

from sklearn.cluster import DBSCAN

db = DBSCAN(eps=0.5, min_samples=5).fit(X)
db.labels_                       # -1 for outliers, ellers klyngenummer
db.core_sample_indices_          # indeksene til kjernepunktene
n_clusters = len(set(db.labels_)) - (1 if -1 in db.labels_ else 0)
n_outliers = np.sum(db.labels_ == -1)

sklearn teller punktet selv med blant naboene, så min_samples=5 der tilsvarer fire naboer i pseudokoden over. Prøv eps for lav og se antall klynger eksplodere og outliers fylle mellomrommene; det er figuren i Ord. 2024 spm. 30.

05 · Avstander i høye dimensjoner

Simuleringen bak figur 22

Notatene · avsnitt 3.1.4 · s. 46–47

To tilfeldige punkter i enhetskuben \([0,1]^d\), avstanden mellom dem, gjentatt 1000 ganger for seks verdier av \(d\):

def get_cube_dist(dim):
    dims = range(dim)
    P1 = np.array([np.random.uniform() for _ in dims])
    P2 = np.array([np.random.uniform() for _ in dims])
    dist = np.linalg.norm(P1 - P2)
    return dist

n_iter = 1000
grid = [2, 3]
dims = [2, 3, 10, 100, 1000, 10000]
fig, axs = plt.subplots(grid[0], grid[1])

_i = 0
for _x in range(grid[0]):
    for _y in range(grid[1]):
        dim = dims[_i]
        _i += 1
        dists = [get_cube_dist(dim) for _ in range(n_iter)]
        axs[_x, _y].hist(dists, label=f"d={dim}")
        axs[_x, _y].legend()
        axs[_x, _y].set_xlim(left=0)
plt.show()

Les av middelverdi og spredning per \(d\): middelverdien vokser omtrent som \(\sqrt{d/6}\), spredningen holder seg omtrent konstant, så spredning delt på middelverdi går mot null. Det er concentration of distances, og grunnen til at avstandsbaserte algoritmer trenger dimensjonsreduksjon først.

06 · PCA

Kovarians, egenverdier og PCA i sklearn

Notatene · avsnitt 3.2.1 · s. 50–52 (sklearn-koden); numpy-delen er forslag

Regnestykket fra 3B i numpy, for å se at PCA ikke gjør noe magisk: sentrer, kovariansmatrise, egenverdier, sorter, projiser.

x1 = np.array([1, 2, 3, 4, 5])
x2 = np.array([1.6, 4.2, 5.7, 8.4, 9.2])
X = np.vstack((x1, x2)).T                  # shape (5, 2): én rad per datapunkt
Xc = X - X.mean(axis=0)                    # trekk fra gjennomsnittet: x̄1 = 3, x̄2 = 5.82
S = Xc.T @ Xc / (len(X) - 1)               # likning (103)–(104): [[2.5, 4.85], [4.85, 9.63]]
assert np.allclose(S, np.cov(X, rowvar=False))

lam, E = np.linalg.eigh(S)                 # egenverdier (stigende) og egenvektorer som kolonner
order = lam.argsort()[::-1]                # sorter synkende: PC1 først
lam, E = lam[order], E[:, order]           # lam ≈ [12.08, 0.046], E[:, 0] ≈ [0.45, 0.89]
andel = lam / lam.sum()                    # [0.996, 0.004]: PC1 forklarer 99.6 %
X_pc = Xc @ E                              # koordinater i PC-systemet, det pca.transform gjør
X_1d = X_pc[:, :1]                         # behold bare PC1: fra to features til én

Det samme med scikit-learn

from sklearn.decomposition import PCA
x1 = np.array([1,2,3,4,5])
x2 = np.array([1.6,4.2,5.7,8.4,9.2])

pca = PCA(n_components=2)
X = np.vstack((x1, x2)).T
X_pca = pca.fit_transform(X)
PC1 = X_pca[:,0]
PC2 = X_pca[:,1]

plt.scatter(x1, x2, color='blue', label='Original Data', marker='*')
plt.scatter(PC1, PC2, color='red', label='PCA Transformed Data')
plt.legend()
plt.show()

Med n_components=2 er dataene bare rotert til PC-systemet, ikke redusert. Til én dimensjon: bytt to linjer, pca = PCA(n_components=1) og plt.scatter(X_pca, np.zeros_like(X_pca), ...). Her brukes fit_transform på hele datasettet, så resultatet kan ikke brukes til å evaluere en modell. pca.components_ er egenvektorene (radvis), pca.explained_variance_ egenverdiene og pca.explained_variance_ratio_ andelen (forslag).

S-kurven: fit på trening, transform på test

S_points, S_color = sklearn.datasets.make_s_curve(n_samples=1000)
x, y, z = S_points.T
pca = sklearn.decomposition.PCA(n_components=2)
X_train, X_test, y_train, y_test = train_test_split(S_points, S_color)
pca.fit(X_train)
S_pca = pca.transform(X_test)
plt.scatter(S_pca[:,0], S_pca[:,1], c=y_test)
plt.show()

God praksis: .fit på treningsdataene, .transform på testdataene. Det går fordi PCA lager basisvektorer som kan brukes på nye punkter; sammenlikn t-SNE under. Resultatet er en S i planet: dybderetningen hadde nesten ingen varians.

MNIST: 784 → 2

(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train = x_train.reshape(60000, 784).astype("float32") / 255
x_test = x_test.reshape(10000, 784).astype("float32") / 255
y_train = y_train.astype("float32")

pca.fit(x_train)

To lineære akser er ikke egnet til å representere variansen i MNIST: sifrene overlapper nesten helt i plottet. Merk at siste linje bruker fit_transform på testdataene og dermed tilpasser på nytt; pca.transform(x_test) ville brukt tilpasningen fra treningsdataene (forslag).

07 · t-SNE

Én linje, og ingen transform

Notatene · avsnitt 3.2.2 · s. 53; KL-funksjonen er forslag

Samme MNIST-data, men med t-SNE i stedet for PCA:

tsne = TSNE(n_components=2, learning_rate='auto', init='random', perplexity=3)
X_embedded = tsne.fit_transform(X)

Klassen ligger i sklearn.manifold. perplexity styrer variansen i Gaussen rundt hvert punkt (effektivt antall naboer), init='random' er steg 1 (tilfeldig plassering) og fit_transform er steg 2 (gradient descent på KL-divergensen). Det finnes ingen tsne.transform for nye data: modellen er ikke-parametrisk, resultatet er posisjonene til akkurat disse punktene.

def kl_divergence(P, Q):                     # likning (114), for diskrete fordelinger
    P, Q = np.asarray(P), np.asarray(Q)
    return np.sum(P * np.log(P / Q))         # forventning under P av log(P/Q); ≥ 0, ikke symmetrisk

kl_divergence([0.5, 0.25, 0.25], [0.5, 0.25, 0.25])   # 0.0
kl_divergence([0.5, 0.25, 0.25], [0.2, 0.4, 0.4])     # 0.223
kl_divergence([0.2, 0.4, 0.4], [0.5, 0.25, 0.25])     # 0.193: en annen verdi den andre veien
08 · Anomalideteksjon

Tre måter å si «anomali» på

Notatene · avsnitt 3.3.1–3.3.3 · s. 54–55; pseudokoden for isolasjonstreet er forslag

Metodene fra 3C som kode. Det er regelen for «anomali» som skiller dem: en terskel på avstand, en label fra modellen, eller en terskel på stilengde.

k-means: avstand til nærmeste sentroide over en prosentil

distances = kmeans.transform(X_test).min(axis=1)

threshold = np.percentile(distances, 95)
outliers = distances > threshold

kmeans er tilpasset på treningsdata først. transform gir en (n, k)-matrise med avstander til hver sentroide, min(axis=1) den korteste per punkt. outliers er et array med True for punktene med avstand over 95 % av dataene; prosentilen må ofte justeres.

DBSCAN: label −1

outliers = dbscan.labels_ == -1

Ingen trenings/test-splitt: DBSCAN er ikke-parametrisk og må ha alle dataene i fit. Velg eps og min_samples først.

Isolation Forest

iso_forest = IsolationForest(n_estimators=100, contamination=0.05)
iso_forest.fit(X_train)
outliers = iso_forest.predict(X_test) == -1

Klassen ligger i sklearn.ensemble. n_estimators er antall isolasjonstrær, contamination anslått andel anomalier, som setter terskelen på scoren. predict gir −1 for anomalier og 1 for normale; iso_forest.decision_function(X_test) gir selve scoren, lavere er mer anomal (forslag).

def path_length(x, X, rng, depth=0, max_depth=50):   # ett isolasjonstre, for å se mekanismen
    if len(X) <= 1 or depth >= max_depth:
        return depth                                    # alene i løvnoden: stilengden er dybden
    f = rng.integers(X.shape[1])                        # tilfeldig feature
    v = rng.uniform(X[:, f].min(), X[:, f].max())       # tilfeldig splittverdi innenfor noden
    side = X[:, f] < v if x[f] < v else X[:, f] >= v   # følg x sin side av splitten
    return path_length(x, X[side], rng, depth + 1, max_depth)

scores = [np.mean([path_length(x, X_train[rng.choice(len(X_train), 256, replace=False)], rng)
                   for _ in range(100)])                # 100 trær på tilfeldige subsett
          for x in X_test]                              # kort gjennomsnittlig sti = anomali
