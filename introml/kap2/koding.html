02 · Perceptron

Fra bunnen og med sklearn

Notatene · avsnitt 2.1 · s. 35–36

Koden fra logistisk regresjon (1E) gjenbrukes med likning (89) som modell og Rosenblatts regel (91) i stedet for gradienten. To linjer er hele modellen:

activation = sum(weight_i * x_i) + bias
prediction = 1.0 if activation >= 0.0 else 0.0
w = w + learning_rate * (expected - predicted) * x   # x utvidet med et første element 1, w[0] er bias
class Perceptron:
    def __init__(self, learning_rate=0.1, epochs=100):
        self.learning_rate, self.epochs = learning_rate, epochs

    def _add_bias(self, x):
        return np.hstack([np.ones((x.shape[0], 1)), x])   # (N, d) -> (N, d+1): første kolonne = 1

    def predict(self, x):
        z = self._add_bias(x) @ self.w                     # (N,)
        return np.where(z >= 0, 1, 0)                      # Heaviside

    def fit(self, x, y):
        xb = self._add_bias(x)
        self.w = np.zeros(xb.shape[1])
        for _ in range(self.epochs):                       # én epoke = alle datapunkter én gang
            for xi, yi in zip(xb, y):                      # ett punkt om gangen, ikke hele batchen
                y_hat = 1 if xi @ self.w >= 0 else 0
                self.w = self.w + self.learning_rate * (yi - y_hat) * xi   # likning (91); 0 om riktig
        return self
Forskjellen fra logistisk regresjon i kode

Samme løkke, men (1) ingen sigmoid og ingen tapsfunksjon å derivere, (2) oppdateringen skjer per datapunkt og bare når prediksjonen er feil, og (3) \((y - \hat{y})\) er alltid \(-1\), \(0\) eller \(1\). Er dataene lineært separerbare, stopper oppdateringene av seg selv; er de ikke det, fortsetter de for alltid, så epochs må begrense løkka.

Det samme med scikit-learn

from sklearn.datasets import make_blobs
from sklearn.linear_model import Perceptron

perceptron = Perceptron().fit(X_train, y_train)
y_pred = perceptron.predict(X_test)
ws = perceptron.coef_          # vektene
bs = perceptron.intercept_     # bias

Perceptron er en wrapper rundt SGDClassifier med loss="perceptron" og learning_rate="constant". Vil du ha logistisk regresjon i stedet, er det samme klasse med loss="log_loss".

03 · Flere klasser

Vektvektor blir vektmatrise

Notatene · avsnitt 2.1 · s. 36 (likning 92 og shape-koden)

Med \(k\) klasser får modellen én output-node per klasse, og vektene blir en matrise. Oppdateringen (92) er den samme regelen anvendt på hver output-node \(j\) for seg. Targets må da være one-hot: \(y_j = 1\) for riktig klasse, 0 ellers.

perceptron = Perceptron().fit(X_train, y_train)
ws = perceptron.coef_
bs = perceptron.intercept_
print("Features:", X.shape[1])          # 2
print("Classes:", len(list(set(y))))    # 3
print("Weights:", ws.shape)             # (3, 2): én rad per klasse, én kolonne per feature
print("Biases:", bs.shape)              # (3,)
def fit_multiclass(x, y, n_classes, learning_rate=0.1, epochs=100):
    xb = np.hstack([np.ones((x.shape[0], 1)), x])      # (N, d+1)
    Y = np.eye(n_classes)[y]                            # one-hot, (N, k)
    W = np.zeros((xb.shape[1], n_classes))              # (d+1, k): W[i, j] = vekt fra input i til node j
    for _ in range(epochs):
        for xi, yi in zip(xb, Y):
            y_hat = np.where(xi @ W >= 0, 1, 0)         # (k,): én TLU per klasse
            W += learning_rate * np.outer(xi, yi - y_hat)   # likning (92) for alle i, j samtidig
    return W

def predict_multiclass(W, x):
    xb = np.hstack([np.ones((x.shape[0], 1)), x])
    return np.argmax(xb @ W, axis=1)                    # klassen med størst aktivering

np.outer(xi, yi - y_hat) er en \((d+1) \times k\)-matrise med \((y_j - \hat{y}_j)\,x_i\) i posisjon \((i, j)\): nøyaktig (92). Merk at sklearn lagrer \(W\) transponert, som (klasser, features).

04 · Logiske porter

Tre tall per port

Notatene · avsnitt 2.1 · s. 36 (vektene); koden er forslag
def tlu(w, b):
    return lambda x: 1 if np.dot(w, x) + b >= 0 else 0

NOT = tlu([-1], 0.5)
AND = tlu([1, 1], -1.5)
OR  = tlu([1, 1], -0.5)
NAND = tlu([-1, -1], 1.5)                            # NOT(AND)

def XOR(x):                                          # to lag: OR og NAND, så AND
    return AND([OR(x), NAND(x)])

for x in [(0, 0), (0, 1), (1, 0), (1, 1)]:
    print(x, AND(x), OR(x), XOR(x))                  # 0 0 0 / 0 1 1 / 0 1 1 / 1 1 0

Prøv å trene Perceptron fra 02 på XOR-tabellen: vektene slutter aldri å endre seg, og treffsikkerheten kommer aldri over 3 av 4. Det er den praktiske siden av «ikke lineært separerbart».

05 · Aktiveringsfunksjoner

Fire funksjoner i NumPy

Notatene · avsnitt 2.2 · s. 37 (likning 93–95); koden er forslag
def heaviside(z):  return np.where(z >= 0, 1.0, 0.0)          # perceptron; ikke deriverbar
def sigmoid(z):    return 1 / (1 + np.exp(-z))                  # (93), binær klassifisering i siste lag
def relu(z):       return np.maximum(0, z)                      # (95), skjulte lag
def linear(z):     return z                                     # regresjon i siste lag
def softmax(z):                                                 # (94), flerklasse i siste lag
    e = np.exp(z - np.max(z, axis=-1, keepdims=True))           # trekk fra maks: samme svar, ingen overflow
    return e / np.sum(e, axis=-1, keepdims=True)                # summerer til 1 per datapunkt

# de deriverte (trengs når treningen kommer):
def d_sigmoid(z): s = sigmoid(z); return s * (1 - s)            # likning (15)
def d_relu(z):    return np.where(z > 0, 1.0, 0.0)

Alle er elementvise, så de virker på en hel matrise av aktiveringer om gangen. softmax er den eneste som ser på hele vektoren; axis=-1 gjør at den normaliserer per rad når input er (N, k).

06 · Forward pass

Lag for lag med matriseprodukt

Notatene · avsnitt 2.3 · s. 38–39 (likning 96 og 101); koden er forslag

Likning (101) er ett lag: \(\mathbf{a}^{(1)} = g(W^{(1)} \mathbf{x})\), med \(W\) som \(m \times n\) for \(n\) inn og \(m\) ut. Et nettverk er en liste av slike lag, og en forward pass er en løkke som sender aktiveringen fra ett lag inn i det neste. Bias tas med som en egen vektor \(\mathbf{b}\) per lag (notatene baker den inn som \(a_0 = 1\); resultatet er det samme).

def init_layer(n_in, n_out, g):
    return {"W": np.random.randn(n_out, n_in) * 0.1,   # (m, n): små tilfeldige vekter
            "b": np.zeros(n_out),                       # (m,)
            "g": g}

def forward(layers, x):                                # x: (n_features,) for ett datapunkt
    a = x                                              # a^(0) = x
    for layer in layers:
        z = layer["W"] @ a + layer["b"]                # (m,) = (m, n) @ (n,) + (m,)   likning (96)
        a = layer["g"](z)                              # ikke-lineær transformasjon
    return a                                           # output-laget: ŷ

# arkitektur: 3 features -> 4 -> 4 -> 3 klasser (figur 19)
net = [init_layer(3, 4, relu), init_layer(4, 4, relu), init_layer(4, 3, softmax)]
y_hat = forward(net, x)                                # (3,), summerer til 1
klasse = np.argmax(y_hat)

def n_params(layers):
    return sum(l["W"].size + l["b"].size for l in layers)   # 3*4+4 + 4*4+4 + 4*3+3 = 51
Hele batchen på én gang

Med \(X\) som \((N, n)\) skriver man z = a @ W.T + b, som gir \((N, m)\). Da er én rad per datapunkt, og softmax med axis=-1 normaliserer hver rad. Sjekk shapes etter hvert lag; dimensjonssjekken i notatene (\(3 \times 2\) ganger \(2 \times 1\) gir \(3 \times 1\)) er den samme sjekken.

Sjekk forståelsen · Middels
Bytt relu med linear i begge de skjulte lagene i net. Hva kan nettverket da, og hvorfor?
Bare det et enkelt lag kan. Uten ikke-linearitet er forward pass \(\mathrm{softmax}(W_3 (W_2 (W_1 x + b_1) + b_2) + b_3)\), og produktet av matriser er én matrise: nettverket kollapser til en lineær modell med softmax, altså multinomisk logistisk regresjon. Kjør det på XOR-data og se at det ikke lærer.
07 · Keras

Bygge, trene og predikere

Notatene · avsnitt 2.5 · s. 41–43

Kurset anbefaler Keras og tensorflow. De grunnleggende byggesteinene i tensorflow er keras-operasjoner. En \((10, 3)\)-dimensjonal tensor fylt med ettall til å eksperimentere med:

from keras import ops
x = ops.ones((10, 3))

Et enkelt nettverk med to indre lag på henholdsvis 6 og 7 noder og et output-lag med 2 noder:

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential()
model.add(Dense(6, activation="relu", name="layer1"))
model.add(Dense(7, activation="relu", name="layer2"))
model.add(Dense(2, activation="softmax", name="output"))
model(x)                     # (10, 2): to ulike, foreløpig meningsløse tall gjentatt 10 ganger

Modellen heter Sequential fordi lagene kommer i en lineær sekvens, slik at dataene flyter sekvensielt fra input- til output-laget. Lagene heter Dense fordi alle nodene har koblinger til alle nodene i forrige og neste lag; koblingen er så tett som den kan være. Alle lagene initialiseres med tilfeldige verdier. To andre måter å skrive det samme:

model = Sequential(
    Dense(6, activation="relu", name="layer1"),
    Dense(7, activation="relu", name="layer2"),
    Dense(2, activation="softmax", name="output"),
)                            # hele modellen direkte, fra en liste av lag
model(x)

layer1 = Dense(6, activation="relu", name="layer1")
layer2 = Dense(7, activation="relu", name="layer2")
layer3 = Dense(2, activation="softmax", name="output")
layer3(layer2(layer1(x)))    # sekvensen eksplisitt; gir ikke noe modell-objekt

Det viktige å huske er at lag oppfører seg som elementer i en liste: model.layers gir lista over lagene modellen består av. Et enkelt mentalt bilde av et nevralt nettverk i Python er lag stablet oppå hverandre.

Oppgave fra notatene2.5 · s. 42

Lager vi modellen bare ved å stable lagene, uten å evaluere den (for eksempel på tensoren x), har den ingen vekter: model.weights gir en tom liste [], og model.summary() viser Output shape=?. Modellparametrene finnes altså ikke. Hva er grunnen til dette?

Svar fra notatene

Vi kjørte modellen på en tensor med shape \((10, 3)\) selv om ingen av lagene har 3 noder. Grunnen er at modellens input er et objekt, ikke av typen keras.layers, så input vises ikke som et lag. Før modellen kjenner input-dimensjonen vet den ikke hvor mange parametre den består av (første lag trenger \(n \cdot m\) vekter, og \(n\) er ukjent). Enten evaluerer vi modellen på en input-tensor, eller vi spesifiserer input-shape:

model = keras.Sequential()
model.add(keras.Input(shape=(3,)))
model.add(Dense(6, activation="relu", name="layer1"))
model.summary()              # output shape 6, 24 parametre: 3·6 vekter + 6 bias
model(x).shape               # TensorShape([10, 6]): 10 instanser inn, 6 noder ut

Det følger vanlig matrisemultiplikasjon; tegn opp tensordimensjonene om du er usikker. Shape på modellens output svarer alltid til antall noder i siste lag.

Kompilere, trene, evaluere, lagre

Når modellen kompileres velger vi metoden som optimaliserer parametrene under trening, tapsfunksjonen, og eventuelle metrikker som beregnes underveis. Kurset bruker optimizer=keras.optimizers.SGD(), og tapsfunksjonen må passe til oppgaven og dataene. Treningen:

history = model.fit(x_train, y_train, batch_size=64,
                    epochs=10, validation_data=(x_val, y_val))

train_losses = history.history["loss"]
val_losses = history.history["val_loss"]
epochs = np.arange(1, len(train_losses) + 1)
plt.plot(epochs, train_losses, label="Train loss")
plt.plot(epochs, val_losses, label="Validation loss")
plt.xlabel("Epochs")
plt.ylabel("Loss")
plt.legend()
plt.show()

Beregnede metrikker lagres i history, hvert steg i SGD bruker 64 datapunkter (batch size), modellen trenes i 10 epoker, og den evalueres på valideringsdata underveis. Som i 1C er det lurt å stanse treningen når både trenings- og valideringstapet flater ut, men før tapet på treningsdataene blir mye mindre enn tapet på valideringsdataene, siden det er et typisk tegn på overtilpasning. Keras har et early stopping-kriterium der vi angir hva som skal monitoreres, vanligst monitor="val_loss", og hvor tålmodig læringsalgoritmen skal være før treningen stoppes.

model.compile(optimizer=keras.optimizers.SGD(), loss="binary_crossentropy", metrics=["accuracy"])

from keras.callbacks import EarlyStopping
stopp = EarlyStopping(monitor="val_loss", patience=5, restore_best_weights=True)   # tålmodighet: 5 epoker uten bedring
history = model.fit(x_train, y_train, batch_size=64, epochs=200,
                    validation_data=(x_val, y_val), callbacks=[stopp])

Prinsipielt jobber vi med nevrale nettverk som med andre maskinlæringsmodeller, men med større frihet i valg av arkitektur og antall parametre. Hele treningsprosessen koker ned til:

08 · Oppsummering

Det du bør kunne skrive

PerceptronUtvid x med 1, z = x @ w, y_hat = z >= 0, w += lr * (y - y_hat) * x per punkt.
Flere klasserOne-hot targets, W som (d+1, k), W += lr * outer(x, y - y_hat), argmax for klasse.
Shapessklearn: coef_ (klasser, features), intercept_ (klasser,). Eget lag: W (ut, inn), b (ut,).
Aktiveringsigmoid, relu, linear elementvis; softmax per rad med maks trukket fra.
Forwardfor layer: a = g(W @ a + b). Tell parametre: Σ (ut·inn + ut).
XOREtt lag klarer det ikke; OR + NAND → AND gjør det.
KerasSequential + Dense-lag; Input(shape) før vektene finnes; compile → fit → predict → evaluate → save.
fitbatch_size = punkter per SGD-steg, epochs = runder over alle data, validation_data + early stopping på val_loss.
